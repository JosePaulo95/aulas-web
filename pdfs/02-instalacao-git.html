Instalando o Git no Windows

Git e GitHub · Tempo estimado: 10 minutos

O Git é um programa que guarda o histórico do seu projeto: cada vez que você salva uma versão, ele registra. Assim, se algo der errado, dá para voltar a uma versão anterior. Vamos instalá-lo no seu computador. Ele é gratuito.

Este tutorial é para Windows. Se você usa Mac ou Linux, os passos são parecidos, mas podem ser ligeiramente diferentes (nas telas e nos nomes dos botões).

1Baixar o instalador

Abra o navegador e pesquise git download no Google (o site certo é o git-scm.com). Se preferir, entre direto neste link: git-scm.com/downloads.

Com a aba Windows selecionada, clique em Click here to download (onde está a seta vermelha). O download começa sozinho.

Como saber se é o arquivo certo: o nome vai ser mais ou menos assim: Git-2.55.0-64-bit.exe. O número da versão pode estar diferente (o Git é atualizado com frequência). Isso não é problema. O importante é que seja um executável, ou seja, termine em .exe.

2Instalar

Abra a pasta Downloads e dê dois cliques no arquivo .exe. Se o Windows perguntar se você quer permitir alterações no computador, clique em Sim.

Vão aparecer várias telas com opções técnicas. Você não precisa entender todas: basta ir clicando em Next, Next, Next... até aparecer o botão Install. Clique nele, espere terminar e clique em Finish.

Uma exceção: na tela do editor padrão, o Git vem com o Vim, um editor difícil de usar para quem está começando. Troque por Notepad ou Visual Studio Code. Todo o resto pode ficar como está.

3Abrir o CMD

O CMD (Prompt de Comando) é uma janela preta onde o computador recebe comandos digitados por nós. Para abrir:

  • Clique no símbolo do Windows (a janelinha no canto inferior esquerdo da tela) para abrir o menu;
  • Digite cmd. Não é preciso clicar em nenhum campo, basta começar a digitar;
  • Clique em Prompt de Comando (ou aperte Enter).
Outra forma: aperte as teclas Windows + R, digite cmd e aperte Enter.

4Testar se instalou direito

Na janela preta, digite o comando abaixo e aperte Enter:

git --version

Se aparecer algo como git version 2.55.0.windows.1, o Git foi instalado com sucesso! Os números podem ser diferentes.

Apareceu um erro dizendo que o comando "não é reconhecido"? Isso costuma acontecer quando o CMD já estava aberto antes da instalação. Feche a janela preta, abra outra (passo 3) e tente de novo.

5Configurar seu nome e e-mail

O Git precisa saber quem está registrando as versões. Faça isso uma única vez, no CMD, trocando pelos seus dados (mantenha as aspas). Use o mesmo e-mail da sua conta do GitHub:

git config --global user.name "Seu Nome"
git config --global user.email "seu-email@exemplo.com"

Aperte Enter depois de cada linha. Se não aparecer nenhuma mensagem, é porque deu certo.

  • Instalei clicando em Next até o final
  • Abri o CMD pelo menu do Windows

  • Configurei meu nome e meu e-mail no Git
