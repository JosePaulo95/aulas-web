Criando sua conta no GitHub

Git e GitHub · Tempo estimado: 5 minutos

O GitHub é o site onde guardamos nossos projetos na internet (como um "Google Drive" para código). Vamos precisar de uma conta gratuita para as próximas aulas.

Antes de começar: tenha em mãos um e-mail que você consiga abrir agora, pois o GitHub vai enviar um código de confirmação.

1Acessar o site

Abra o navegador e entre em github.com. No canto superior direito, clique em Sign up (ou digite seu e-mail no campo do meio e clique em Sign up for GitHub).

2Preencher o formulário

Na página Create your free account, preencha:

CampoO que colocar
EmailSeu e-mail (o mesmo que você vai abrir para confirmar)
PasswordMínimo 15 caracteres, ou 8 com número e letra minúscula
UsernameSeu nome de usuário público. Só letras, números e hífen simples
Country/RegionBrazil
Email preferencesOpcional. Pode deixar desmarcado
Escolha o username com carinho. Ele aparece no endereço dos seus projetos (github.com/seu-usuario) e no seu portfólio. Prefira algo simples e apropriado, como nome-sobrenome.
Senha: anote em um lugar seguro e não compartilhe com colegas.

3Criar a conta e verificar

Clique no botão verde Create account. Em seguida o GitHub vai pedir:

  • uma verificação rápida (um pequeno desafio para provar que você não é um robô);
  • um código de 8 dígitos enviado para o seu e-mail. Abra a caixa de entrada (olhe também o spam), copie o código e cole na tela do GitHub.

Depois disso, o GitHub faz algumas perguntas de personalização. Pode pular todas.

4Testar o login

Para ter certeza de que deu certo, saia da conta e entre de novo em github.com/login.

  • Digite seu username (ou e-mail) e a senha;
  • Clique em Sign in;
  • Esqueceu a senha? Use Forgot password?.
Se o seu perfil abriu, sua conta está pronta.

✓Checklist final

  • Criei minha conta e confirmei o e-mail
  • Anotei meu username e minha senha
  • Consegui entrar em github.com/login
  • Vou usar o mesmo e-mail no Git
