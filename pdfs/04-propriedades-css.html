CSS · Guia rápido para consultar durante as aulas e os projetos

1

Cor e texto

color: teal;
Cor da letra. Aceita nome (red) ou hex (#16a89c)
background-color: #123f63;
Cor de fundo (pinta conteúdo e padding, não a margin)
font-family: Arial, sans-serif;
Fonte. Sempre ponha uma reserva no final
font-size: 18px;
Tamanho da letra (16px é o normal)
font-weight: 700;
Grossura: 400 normal, 700 negrito
text-align: center;
Alinha o texto na caixa: left, center, right
line-height: 1.6;
Altura da linha, sem unidade. Dá respiro ao texto
text-decoration: none;
Tira (none) ou põe (underline) o sublinhado
2

A caixa

width: 200px;
Largura do conteúdo (ou da caixa toda com border-box)
max-width: 420px;
Largura máxima: encolhe em telas pequenas, nunca passa disso
padding: 10px 20px;
Espaço por dentro. 1, 2 ou 4 valores
border: 2px solid navy;
Borda: tamanho, tipo e cor, nesta ordem
border-radius: 12px;
Cantos arredondados. 50% numa caixa quadrada vira círculo
margin: 0 auto;
Espaço por fora. 0 auto centraliza um bloco com largura
box-sizing: border-box;
O width passa a valer a caixa inteira. Use em * { }
1, 2 ou 4 valores (padding e margin): 10px = 4 lados · 10px 20px = cima/baixo e esquerda/direita · 10px 20px 30px 40px = cima, direita, baixo, esquerda (sentido do relógio).

Aparência, posição e seletores

3

Aparência e efeitos

box-shadow: 0 6px 16px rgba(0,0,0,.2);
Sombra: X, Y, desfoque e cor. Use um gerador de sombras
background-image: url("img.png");
Imagem de fundo (o caminho vale a partir do arquivo .css)
background-size: cover;
cover cobre tudo · contain mostra inteira
background-repeat: no-repeat;
Impede a imagem de se repetir em ladrilho
cursor: pointer;
Muda o mouse (pointer = mãozinha)
transition: 0.3s;
Mudança suave. Vai na regra normal, não no :hover
transform: scale(1.1);
Move (translate), gira (rotate) ou aumenta (scale)
4

Posição

position: relative;
O elemento se move a partir do seu lugar. Sem afetar os vizinhos
position: absolute;
Sai do fluxo e vai para qualquer lugar do pai com relative
top / left / right / bottom
Distância a partir de cada lado. Só funcionam com position
Receita: position: relative no pai e position: absolute no filho. Sem position no pai, o filho usa a página inteira como referência.
5

Seletores

p { }
Tag: todos os elementos daquele tipo
.aviso { }
Classe: quem tem class="aviso" (HTML sem ponto)
#vip { }
Id: o único com id="vip"
h1, h2 { }
Vírgula = este e aquele
nav a { }
Espaço = "dentro de", em qualquer nível
.menu > li { }
Filho direto: só um nível abaixo
.botao:hover { }
Pseudo-classe: enquanto o mouse está em cima
li:first-child { }
Pelo lugar na lista: :first-child, :last-child
Quando duas regras brigam: vence a de maior força (id 100 · classe 10 · tag 1). Com a mesma força, vence a última do arquivo. Prefira seletores simples, como uma classe só.

Display e Flexbox

6

Display

display: block;
Ocupa a linha inteira. Aceita largura e altura (div, p)
display: inline;
Fica na linha do texto. Ignora largura e altura (span, a)
display: inline-block;
Fica na linha, mas aceita largura e altura
7

Flexbox · no container (o pai)

display: flex;
Liga o flexbox: os filhos viram itens
flex-direction: column;
row (padrão, em linha) ou column (em coluna)
justify-content: space-between;
Distribui no eixo principal: flex-start, center, flex-end, space-between, space-around, space-evenly
align-items: center;
Alinha no eixo transversal: stretch, flex-start, center, flex-end
gap: 10px;
Espaço fixo entre os itens
flex-wrap: wrap;
Quebra de linha quando os itens não cabem
Macete: justify = eixo principal · align = o outro eixo. Em flex-direction: column os eixos trocam: o principal vira vertical.
8

Flexbox · nos itens (os filhos)

flex: 1;
O item cresce e divide o espaço livre com os irmãos
flex-grow: 2;
Quanto cresce: 2 ocupa o dobro de 1
align-self: flex-end;
Alinhamento só deste item, ignorando o align-items do pai
9

Receitas prontas

display: flex; justify-content: center; align-items: center;
Centralizar no meio da caixa
display: flex; justify-content: space-between;
Menu: logo de um lado, links do outro
display: flex; flex-wrap: wrap; gap: 16px;
Galeria de cards que quebra de linha
