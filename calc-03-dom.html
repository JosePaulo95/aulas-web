O que é o DOM

O navegador transforma o HTML numa árvore

  • document
    • html
      • head
        • title
      • body
        • div.caixa
          • h1
          • p ×2
          • input#idade
          • div.botoes
            • button ×6
          • p#resultado
          • ul#historico

Com ↓ (só você)

  • Cada ↓ desce um nível: html → head e body → title e .caixa → o que tem na caixa → os botões.

Falar

  • Quando o navegador lê o HTML, ele não guarda o texto: monta uma árvore. Cada tag vira um galho.
  • Isso tem nome: DOM, Document Object Model. “Modelo de objetos do documento.”
  • Pai e filho: quem está dentro é filho. O h1 é filho da .caixa, que é filha do body.

Ilustrar no navegador

  • No site: F12 → aba Elements. Abrir e fechar os triângulos: “é a mesma árvore, só que deitada”.
  • Passar o mouse num nó do Elements: o navegador pinta o elemento na página.

document

A raiz da árvore

  • document.titleo título da aba
  • document.bodyo <body> inteiro
  • document.querySelector(…)procura um elemento lá dentro

O ponto (.) quer dizer “de dentro de”.

rodar JavaScript

Dois jeitos de ligar o JS

  • <script> … </script>o código fica direto no HTML, no fim do body
  • <script src="aula.js">o código fica num arquivo .js separado

Salvou? Recarregue a página para ver.

ver o que acontece

Pra espiar o código funcionando

  • alert('oi')abre uma janelinha e pausa a página
  • console.log('oi')escreve no Console (F12 ou Ctrl+Shift+J)

O console é o seu melhor amigo pra entender o que o código faz.

querySelector

Seletores: os mesmos do CSS

  • 'h1'por tag
  • '.botoes'por classe (com ponto)
  • '#idade'por id (com #)
  • '.caixa p'um dentro do outro

querySelector: o primeiro que achar (ou null)  ·  querySelectorAll: todos, numa lista

funções

Um bloco de código com nome

  • function cumprimenta(nome) { … }declarar: ensina o que fazer
  • cumprimenta('Maria')chamar: manda fazer, passando o nome
  • nomeo parâmetro: muda a cada chamada

Declarar não executa nada. Quem executa é a chamada.

onclick

O botão chama a função

  • <button onclick="cumprimenta('Maria')">ao clicar, o botão chama a função
  • calcular('cachorro', 7, '🐕')cada botão manda parâmetros diferentes

A mesma função serve pra todos os botões. Só mudam os parâmetros.

alterando valores

Ler e escrever na página

  • campo.valueo que a pessoa digitou (sempre texto)
  • elemento.textContento texto de dentro do elemento
  • resultado.textContent = '…'escreve na página

Sem o = lê. Com o = escreve.

Falar

Falar

Recap

O JS pega, muda e cria

  • querySelector / querySelectorAll: pegar
  • .textContent: o texto do elemento
  • .value: o que foi digitado (é texto!)
  • innerHTML: só quando você escreveu o HTML
  • classList.add / remove / toggle
  • createElement + append: criar
