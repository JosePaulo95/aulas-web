# JOGOS — Detalhamento de módulos (específico)

Base: ementa original (aba JOGOS da planilha). Os módulos comuns às 3 trilhas (lógica de programação, HTML+CSS, JS Web/DOM, Git) estão em [trilha-base-detalhamento.md](trilha-base-detalhamento.md). Aqui ficam só os módulos exclusivos de JOGOS.

Motor de jogo adotado: **Phaser** (JS puro só na parte de lógica de programação, na Trilha Base).

11. Introdução ao desenvolvimento de jogos 2D com motor de jogo, incluindo criação de cenas, objetos e lógica básica de gameplay.
12. Desenvolvimento de jogos 2D com implementação de efeitos visuais e aprimoramento da experiência do usuário.

## Módulo 9 — Jogos Mobile
Ementa original (módulos 18-20):
18. Desenvolvimento de jogos para dispositivos móveis com persistência de dados e salvamento de progresso.
19. Otimização de interface e desempenho para jogos mobile, com foco em usabilidade em diferentes dispositivos.
20. Aprofundamento em desenvolvimento de jogos mobile, incluindo refinamento de mecânicas e experiência do usuário.

Nota: como o jogo é feito em Phaser (web), "mobile" aqui é controles touch + layout responsivo + empacotamento — não desenvolvimento nativo. Módulo enxuto por isso.
