# Questionário — Git e GitHub: primeiros comandos

**1. O que o comando `git init` faz?**
- a) Instala o Git no computador
- b) Cria um repositório novo no GitHub
- c) Transforma a pasta atual em um repositório Git
- d) Baixa um repositório do GitHub para a pasta atual

**2. Depois de rodar `git init`, o que aparece na pasta?**
- a) Uma pasta oculta `.git`, onde fica o histórico
- b) Um arquivo `README.md` com a descrição do projeto
- c) Uma cópia de segurança de todos os arquivos
- d) Um primeiro commit com os arquivos existentes

**3. O que acontece se você apagar a pasta `.git` de um projeto?**
- a) Os arquivos do projeto são apagados junto
- b) Os arquivos continuam, mas o histórico de versões é perdido
- c) O Git recria a pasta automaticamente no próximo commit
- d) O histórico continua salvo nas configurações do Git

**4. Para que servem as configurações `user.name` e `user.email`?**
- a) Criar uma conta no GitHub pelo terminal
- b) Fazer login no GitHub pelo terminal
- c) Definir o autor que aparece nos commits
- d) Proteger o repositório com usuário e senha

**5. Qual é o comando correto para configurar o nome?**
- a) `git config --global username "Maria Silva"`
- b) `git config --global user.name "Maria Silva"`
- c) `git user.name --global "Maria Silva"`
- d) `git config --global user.name Maria Silva`

**6. O que a opção `--global` faz no `git config`?**
- a) Envia a configuração para a conta do GitHub
- b) Aplica a configuração apenas ao repositório atual
- c) Aplica a configuração a todos os computadores da rede
- d) Aplica a configuração a todos os repositórios do seu usuário no computador

**7. Qual a diferença entre repositório local e remoto?**
- a) O local fica no seu computador; o remoto fica em um servidor, como o GitHub
- b) O local é público; o remoto é privado
- c) O local guarda os arquivos; o remoto guarda apenas o histórico
- d) O local é criado com `git clone`; o remoto com `git init`

**8. O que o comando `git status` mostra?**
- a) O histórico de commits do projeto
- b) Se o GitHub está online
- c) O estado dos arquivos: novos, modificados ou preparados
- d) A versão do Git instalada no computador

**9. O que o comando `git add` faz?**
- a) Cria um arquivo novo no projeto
- b) Salva as mudanças no histórico
- c) Envia os arquivos para o GitHub
- d) Prepara as mudanças para entrar no próximo commit

**10. Um aluno fez `git commit`, mas a mudança não aparece no GitHub. Por quê?**
- a) O commit fica só no computador até ele rodar `git push`
- b) Ele esqueceu de rodar `git add` antes
- c) O GitHub demora alguns minutos para atualizar
- d) Ele não configurou o email com `git config`
