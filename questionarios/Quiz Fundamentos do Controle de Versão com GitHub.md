# Questionário — Git e GitHub: conceitos

**1. O que é controle de versão?**
- a) Um sistema que faz backup automático a cada alteração
- b) Um sistema que registra o histórico de alterações dos arquivos
- c) Um sistema que sincroniza arquivos entre computadores
- d) Um sistema que impede alterar arquivos já finalizados

**2. Qual destes problemas o controle de versão resolve?**
- a) Dois arquivos com o mesmo nome na mesma pasta
- b) Arquivos corrompidos por vírus
- c) Não saber quem alterou um arquivo e quando
- d) Erros de lógica no código

**3. O que é o Git?**
- a) Um serviço online para hospedar código
- b) Uma extensão do VS Code para versionar código
- c) Um servidor que armazena o histórico do projeto
- d) Um programa que registra o histórico do projeto no seu computador

**4. Sobre o Git, é correto afirmar que:**
- a) Precisa de internet para registrar cada commit
- b) Consegue registrar versões mesmo sem internet
- c) É gratuito, mas só funciona no Linux
- d) Foi criado pela Microsoft junto com o GitHub

**5. O que é o GitHub?**
- a) Uma plataforma online que hospeda repositórios Git
- b) A interface gráfica oficial do Git
- c) A versão do Git com recursos de nuvem
- d) Um programa necessário para o Git funcionar

**6. Um aluno instalou o Git, mas não tem conta no GitHub. Ele:**
- a) Não consegue usar o Git sem uma conta
- b) Consegue criar repositórios, mas não fazer commits
- c) Consegue criar repositórios e fazer commits no próprio computador
- d) Consegue usar, mas o histórico some ao fechar o terminal

**7. O que é um repositório?**
- a) A pasta onde o Git fica instalado no computador
- b) O projeto acompanhado pelo Git, com arquivos e histórico
- c) O espaço de armazenamento de uma conta no GitHub
- d) O arquivo onde o Git guarda os commits de todos os projetos

**8. No Git, como várias pessoas trabalham no mesmo projeto?**
- a) O arquivo fica bloqueado enquanto alguém está editando
- b) Todos editam uma única cópia na nuvem ao mesmo tempo
- c) As alterações de cada um aparecem automaticamente para os outros
- d) Cada pessoa trabalha na sua cópia e depois as mudanças são juntadas

**9. Uma mudança quebrou o projeto. Como o controle de versão ajuda?**
- a) Permite voltar o projeto para um commit anterior
- b) Identifica e corrige o erro automaticamente
- c) Desfaz a última alteração com Ctrl+Z
- d) Pede ao GitHub para restaurar a última versão estável

**10. O computador de um desenvolvedor quebrou. O que ele consegue recuperar?**
- a) Tudo, pois o Git mantém uma cópia na lixeira
- b) Tudo, pois o Git salva automaticamente na nuvem
- c) O que ele tinha enviado ao GitHub com push
- d) Tudo, inclusive as mudanças que não tinham sido commitadas
