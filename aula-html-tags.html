HTML na Prática

Aula · Fundamentos

HTML

o esqueleto de toda página da web — e as primeiras tags que você vai escrever

De onde a gente parou

O servidor manda um arquivo de texto

Lembra? Você digita o endereço, o DNS traduz, o navegador pede — e a primeira coisa que volta é o HTML.

É nele que o navegador descobre o que escrever na tela e quais outros arquivos ainda precisa baixar. Hoje a gente aprende a escrever esse arquivo.

Parte 1 · A ideia

HTML não é programação

HTML = HyperText Markup Language — linguagem de marcação.

Você não manda o computador “fazer” nada. Você pega um texto e vai etiquetando cada pedaço: isto aqui é um título, isto é um parágrafo, isto é um link.

Igual passar marca-texto numa apostila: o conteúdo já existe, você só diz o que cada parte é.

Parte 1 · A ideia

Anatomia de uma tag

<p>Oi, eu sou um parágrafo.</p>
  ↑                              ↑
  abre                           fecha (tem a barra /)
  • A tag de abertura diz onde começa
  • A de fechamento tem uma / e diz onde termina
  • O que está no meio é o conteúdo

Abriu, fecha. Esqueceu de fechar → o navegador chuta — e geralmente chuta errado.

Parte 1 · A ideia

O esqueleto de um arquivo

<!DOCTYPE html>
<html>
  <head>
    <title>Minha página</title>   <!-- o nome da aba -->
  </head>
  <body>
    <!-- tudo que aparece na tela vem aqui -->
  </body>
</html>
headinformações sobre a página (ninguém vê)
bodyo conteúdo de verdade (todo mundo vê)

Parte 2 · As tags

As tags de hoje

<p><br><h1> <h2> <h3><a href><ul> <li>

Cinco tags. Com elas você já monta uma página inteira de verdade — texto, títulos, links e listas.

Existem mais de 100 tags. Ninguém decora todas: a gente aprende as que usa todo dia e consulta o resto.

Parte 2 · Texto

<p> — parágrafo

você escreve 
<p>Robótica é construir máquinas
que fazem tarefas sozinhas.</p>

<p>Na +ROBOTIC a gente
programa elas.</p>
o navegador mostra

Robótica é construir máquinas que fazem tarefas sozinhas.

Na +ROBOTIC a gente programa elas.

Repare: o navegador ignora onde você apertou Enter. Quem separa os blocos é a tag, não a tecla.

Parte 2 · Texto

<br> — quebra de linha

você escreve 
<p>Rua das Flores, 120<br>
Centro — Guaratinguetá<br>
CEP 12500-000</p>
o navegador mostra

Rua das Flores, 120
Centro — Guaratinguetá
CEP 12500-000

  • <br> não fecha — não existe </br>. Ela não embrulha nada, só faz uma coisa acontecer ali.
  • Use para endereço, verso de poema, letra de música. Não use para dar espaço entre parágrafos — isso é trabalho do <p>.

Parte 2 · Títulos

<h1> a <h3> — títulos

você escreve 
<h1>Curso de Robótica</h1>
<h2>Módulo 1</h2>
<h3>Aula de hoje</h3>
<p>Vamos falar de HTML.</p>
o navegador mostra

Curso de Robótica

Módulo 1

Aula de hoje

Vamos falar de HTML.

Vai de h1 até h6. Você não precisou escolher tamanho de fonte: o navegador já tem um padrão pra cada nível.

Parte 2 · Títulos

Título é hierarquia, não tamanho

  • h1 = o assunto da página inteira — normalmente um só
  • h2 = as seções · h3 = as subseções dentro delas
  • É o índice de um livro: capítulo → seção → tópico
Quer só deixar um texto maior? Isso é trabalho do CSS, na próxima aula. Usar h1 pra isso confunde o Google e os leitores de tela.

Parte 3 · Atributos

Atributos: informação extra na tag

<img src="robo.jpg">
  ↑    ↑        ↑
  tag  atributo valor (entre aspas)

Algumas tags precisam de dados pra funcionar. Só <img> não diz nada — qual imagem? O atributo src responde isso.

Uma tag pode ter vários atributos, sempre no formato nome="valor", dentro da tag de abertura.

Parte 3 · Imagens

<img> — a imagem

você escreve 
<p>Meu robô ficou assim:</p>

<img src="robo.jpg"
     alt="Foto do robô montado">
o navegador mostra

Meu robô ficou assim:

  • Como o <br>, o <img> não fecha — não existe </img>
  • alt = descrição da imagem: aparece se ela não carregar e é o que um leitor de tela fala pra quem não enxerga

Parte 3 · Imagens

A imagem não está dentro do HTML

Lembra da aula passada? O src é só um endereço. O arquivo robo.jpg continua lá fora, sozinho.

  • Ao ler essa linha, o navegador faz outro pedido ao servidor só pra baixar a imagem
  • src="robo.jpg" → arquivo na mesma pasta da sua página
  • src="imagens/robo.jpg" → dentro da pasta imagens
  • src="https://site.com/foto.jpg" → imagem que mora em outro site
Errou o caminho ou renomeou o arquivo? A imagem some e sobra o alt. É o erro mais comum da primeira página de todo mundo.

Parte 3 · Links

<a href> — o link

você escreve 
<p>Pesquise no
<a href="https://google.com">Google</a>
ou veja a
<a href="contato.html">página
de contato</a>.</p>
o navegador mostra

Pesquise no Google ou veja a página de contato.

  • Endereço completo (https://...) → vai pra outro site
  • Só o nome do arquivo (contato.html) → vai pra outra página sua, na mesma pasta

Parte 3 · Links

O hyper do HyperText

O link é a invenção que criou a web: páginas soltas em servidores do mundo inteiro, costuradas umas nas outras.

href="https://..." → outro site href="sobre.html" → sua outra página href="#final" → um ponto desta página

Sem o <a>, a internet seria só um monte de documentos que não se conhecem.

Parte 4 · Listas

<ul> + <li> — lista

você escreve 
<ul>
  <li>Arduino</li>
  <li>Sensor de distância</li>
  <li>Dois motores</li>
</ul>
o navegador mostra
  • Arduino
  • Sensor de distância
  • Dois motores
  • ul = unordered list, a lista inteira — a “caixa”
  • li = list item, cada item dentro dela

Parte 4 · Listas

Tags dentro de tags

Repare no que aconteceu: o <li> mora dentro do <ul>. HTML é feito de caixas dentro de caixas.

<ul>
  <li>Veja o <a href="kit.html">kit completo</a></li>
</ul>

A regra é só uma: a última que abriu é a primeira que fecha. Nunca cruze as tags.

Dica: um nível de indentação (Tab) pra cada caixa. Não muda nada na tela, muda tudo na sua cabeça.

Parte 4 · Bônus

Trocando uma letra: <ol>

você escreve 
<ol>
  <li>Monte o chassi</li>
  <li>Ligue os motores</li>
  <li>Envie o código</li>
</ol>
o navegador mostra
  1. Monte o chassi
  2. Ligue os motores
  3. Envie o código

ordered list: quando a ordem importa, o navegador numera sozinho. Se você inserir um passo no meio, ele renumera tudo.

Juntando tudo

Uma página inteira, de verdade

pagina.html 
<body>
  <h1>Meu robô</h1>
  <p>Ele desvia de obstáculos.</p>

  <h2>Peças</h2>
  <ul>
    <li>Arduino</li>
    <li>Sensor</li>
  </ul>

  <p>Feito na
  <a href="https://mais-robotic.com.br">+ROBOTIC</a>.</p>
</body>
o navegador mostra

Meu robô

Ele desvia de obstáculos.

Peças

  • Arduino
  • Sensor

Feito na +ROBOTIC.

Fecho · Cola

O que levar pra casa

<p></p>parágrafo de texto <br>quebra de linha (não fecha) <h1> <h2> <h3>títulos, do mais importante ao menos <img src="..." alt="...">imagem (não fecha) <a href="..."></a>link para outra página <ul> <li>lista com marcadores <ol> <li>lista numerada

Abriu, fecha. Tag dentro de tag, sempre na ordem. O resto é vocabulário.

Mão na massa

Sua página sobre você

  • Crie index.html com o esqueleto (html, head, body)
  • Um <h1> com seu nome e um <p> se apresentando
  • Um <h2> “Do que eu gosto” + uma <ul> com 3 itens
  • Uma <img> de uma foto salva na mesma pasta (com alt!)
  • Um <a> pro seu site ou jogo favorito

Salve, abra no navegador, mude alguma coisa, salve de novo e aperte F5.

Agora o arquivo é seu — a mudança não some no F5.
