Peça 1 · Versão

Qual versão vai pro ar?

Na mão

pasta do projeto → arrastar / enviar os arquivos

Rápido. Mas é você quem lembra qual é a versão certa.

Pelo Git

git push → branch main → site atualiza sozinho

A versão no ar é sempre a da main.

Produção = a versão que o público vê. Com Git: produção = main.

Falar

  • “Na mão: você pega a pasta e manda. Funciona, mas se mandar a pasta errada, foi a errada pro ar.”
  • “Pelo Git, que vocês já conhecem: o que estiver na main é o que está no ar. Deu push, atualizou.”
  • Palavra nova: produção. “Quando alguém fala ‘subiu pra produção’, quer dizer: está no ar, o público já vê.”
  • Gancho: “Na próxima aula a gente faz dos dois jeitos.”

Peça 2 · Hospedagem

O projeto decide o servidor

HTML, CSS, JSsite estático

Só entrega os arquivos. É o de vocês.

GitHub Pages, Netlify, Vercel

grátis
PHP / WordPressservidor Apache

Hospedagem “compartilhada”, com painel.

Hostinger, Locaweb, HostGator…

mensalidade
Nodecódigo rodando no servidor

Login, banco de dados, pagamento.

Render, Railway, servidor próprio

grátis limitado / pago

E o meu PC? Até dá, mas teria que ficar ligado 24h e exposto na internet. Não vale.

Falar

  • “Não existe um servidor só. O tipo do projeto decide o tipo de hospedagem.”
  • Estático: “é tudo o que vocês fizeram até agora. O servidor só entrega os arquivos, por isso tem de graça.”
  • Apache: “se um dia alguém pedir um WordPress, ou vocês virem um ‘painel de hospedagem’, é esse aqui. É pago por mês.”
  • Node: “quando o site precisa rodar código no servidor, tipo login. Isso é mais pra frente.”
  • “Vocês não precisam disso agora. Só saibam que existe, pra não ficarem perdidos.”

Ilustrar no navegador

  • F12 → Network → recarregar → clicar no primeiro item → Headers → procurar server.
  • Testar 3 ou 4 sites antes de gravar (ex.: um site do governo, um blog WordPress, um .github.io, um .vercel.app). Aparecem Apache, nginx, GitHub.com, Vercel.
  • “Todo site que vocês abrem está em algum servidor desses.”

Peça 3 · Domínio

O nome que a pessoa digita

meusite.github.iográtis

meusite.netlify.appgrátis

meusite.vercel.appgrátis

meusite.com.brpago por ano

  • Toda hospedagem grátis já te dá um nome.
  • Domínio próprio é opcional.
  • Ele é alugado por ano, não comprado pra sempre.
  • .com.br: registro.br

Falar

  • “Os três primeiros vêm de graça junto com a hospedagem. Funciona igualzinho.”
  • “O último é um domínio só seu. Fica mais profissional, mas é pago, e todo ano.”
  • “Não parou de pagar? Perde o nome. Alguém pode registrar depois.”
  • Domínio ≠ hospedagem: “um é o endereço, o outro é a casa. Se paga separado.”

Ilustrar no navegador

  • Abrir registro.br e pesquisar um nome (o da escola, o de um aluno, um bem engraçado). Mostrar “disponível” e o preço. Não comprar.
  • Pesquisar um famoso (ex.: google.com.br): aparece como ocupado.

  • Não recomendar nenhuma empresa. Mostrar duas lado a lado.

Recap
