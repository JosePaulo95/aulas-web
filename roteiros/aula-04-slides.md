## Slide 2 — Arquitetura web (cliente-servidor)

- **Cliente** ⇄ **Servidor**
- Servidor envia: HTML + CSS + JS
- Cliente (navegador) recebe e exibe

## Slide 3 — Tags HTML iniciais

- `<h1>` `<h2>` `<h3>` — títulos (do maior pro menor)
- `<br>` — quebra de linha
- `<a href="pagina.html">texto</a>` — link pra outra página

---

## Slide 4 — VS Code

- **VS Code** — editor de código gratuito
- Cores no código, autocompletar, explorador de arquivos
- code.visualstudio.com

---

## Slide 5 — Exercício de HTML: A Casa em Chamas

- "Sua vez!"
- Jogo: **A Casa em Chamas** — escape usando só `h1`/`h2`/`h3`, `br` e `a href`
- Cada cômodo é uma página HTML — encontre a saída antes que o fogo te alcance

---

## Slide 6 — Mais tags

- `<p>` parágrafo
- `<img>` imagem
- `<ul>` `<li>` listas
- `<div>` `<span>` divisões genéricas
- `<header>` `<main>` `<footer>` tags semânticas

---

## Slide 7 — CSS

- CSS = estilo (cor, fonte, tamanho, espaçamento...)
- Ligando ao HTML:
  ```html
  <style>
    h1 { color: blue; }
  </style>
  ```

---

## Slide 8 — Tags (propriedades CSS)

- `color` — cor do texto
- `background-color` — cor de fundo
- `font-size` — tamanho da fonte
- `font-family` — tipo de fonte
- `text-align` — alinhamento do texto

---

## Slide 9 — Exercício de CSS: estilize sua casa

- "Sua vez!"
- Adicione `<style>` em cada página da sua Casa em Chamas
- Troque cor de fundo, cor dos títulos, fonte
