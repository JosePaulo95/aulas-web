# Plano geral — Trilha FRONT (aulas assíncronas)

## Formato
- Aulas assíncronas de **15-20 min**, gravadas com slide + você falando/mexendo no PC (webcam provavelmente no **canto inferior direito** — os slides não devem ter elementos importantes ali).
- Público: **ensino médio, zero conhecimento prévio** em programação.
- Slides = apoio visual enxuto (palavras-chave, não parágrafos). A explicação completa vem da sua fala.
- Ambiente de prática: **console do DevTools do navegador** (principal, zero fricção) + **editor online** (replit ou PlayCode) como alternativa pra quem quiser algo mais persistente/visual. Apresentar as duas opções já na Aula 1.

## Estrutura recorrente de cada aula
1. Gancho/abertura (analogia do dia a dia)
2. Conceito(s) do dia
3. Demonstração prática ao vivo (código sendo escrito na hora)
4. Mini-desafio pro aluno tentar sozinho
5. Recap rápido + gancho pra próxima aula

## Identidade visual
- Modelo escolhido: **Modelo B — "Jovem Energético"** (cards coloridos com sombra, tag de número da aula, fundo navy escuro).
- Paleta (extraída da logo +ROBOTIC):
  - Navy `003960` (fundo)
  - Navy escuro `0A1F30` (cards/variação)
  - Cinza-azulado `8C9DBA` (texto secundário)
  - Teal `00A99D`
  - Lima `D9E021`
  - Laranja `FBB03B`
- **Regra fixa: nada de elementos no canto inferior direito** — é onde a câmera vai ficar por cima do slide.
- Logo no canto superior (esquerdo no slide de título, direito nos slides de conteúdo).

## Mapa das 20 aulas (ementa FRONT)
1. Fundamentos de lógica de programação com JS (variáveis, operadores, estruturas de controle) ← **Aula 1**
2. Algoritmos com funções, listas e estruturas de dados básicas ← **Aula 2**
3. Prática de lógica de programação com exercícios guiados
4. HTML e CSS — estruturação de páginas
5. CSS — classes, posicionamento, Flexbox
6. CSS avançado — cabeçalho, rodapé, variáveis
7. Responsividade e publicação de projetos
8. Introdução ao JavaScript para páginas dinâmicas
9. Manipulação do DOM
10. Git e GitHub
11. Arrays e métodos de coleções
12. localStorage e estado local
13. Validação de formulários
14. Consumo de dados de APIs
15. Requisições HTTP
16. Introdução ao TypeScript
17. POO com TypeScript
18. Modelagem de dados
19. React + APIs externas
20. React com TypeScript
