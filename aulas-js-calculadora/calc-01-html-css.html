Calculadora: o visual

HTML pronto, layout com grid. A lógica fica pra aula de JS.

calculadora/index.html

Falar

  • Hoje a gente monta essa calculadora. Só o visual: nas próximas aulas o JS faz ela funcionar.
  • Reparem nos botões + e =, mais altos, e no 0, mais largo. É isso que vai pedir uma ferramenta nova.

Tempo

  • 0:00 → 0:30

Com ↓ (só você)

  • Passos: começa sem a table → ↓ mostra <table> → ↓ 1ª linha → todas as linhas sem span (o + e o = ficam fora do lugar, sobra buraco) → rowspan e colspan (encaixa).
  • O visual das células já está aplicado escondido, igual ao bloco do visor.

Falar

  • Muita calculadora antiga na internet é feita assim. E funciona: rowspan="2" faz a célula ocupar duas linhas.
  • O problema: <table> é pra dados (horários, preços, planilha). Leitor de tela anuncia “tabela com 5 linhas”, e o layout fica preso no HTML.
  • Guardem a ideia de “ocupar duas casas”. Ela volta no jeito certo.

Tempo

  • ~1 min.

Com ↓ (só você)

  • ↓ digita o próximo pedaço do código; o navegador atualiza quando termina. ↓ durante a digitação completa na hora. ↑ volta.
  • Passos: caixa + visor → ↓ digita todos os botões de uma vez.

Falar

  • Uma div por fora, o visor, e uma div só com os botões. Esta é a que vai virar grade.
  • Os botões altos e o largo já ganham uma classe agora (alto, largo). Vamos usar já já.
  • Sem CSS fica feio assim mesmo: os botões só vão um do lado do outro, como palavras.

Tempo

  • 0:30 → 1:30 · no zip o HTML já vem pronto, não precisa digitar junto

Com ↓ (só você)

  • Passos: display: flex → ↓ digita todo o resto (wrap + gap, botões com 50px).
  • Todos os botões do mesmo tamanho, 4 por linha, como uma tabela.

Falar

  • Com o que vimos na aula passada: flex + wrap. Quatro por linha, ficou bom!
  • Agora o + alto… ele cresce, mas a linha cresce junto. O flex pensa em uma fila de cada vez: não sabe que existe uma linha de baixo.
  • Pra um botão ocupar duas linhas, precisamos de algo que enxergue linhas e colunas.

Tempo

  • ~1 min. Não tentar “consertar” o flex.

Com ↓ (só você)

  • Passos: display: grid → 4 colunas de 50px → troca pra 1fr → gap → estilo dos botões → .alto (span 2) → .largo (span 2).
  • O visual do visor e da caixa já está aplicado (bloco anterior) e aparece só como comentário.

Falar

  • Flexbox é pra uma fila. Calculadora é um tabuleiro: linhas e colunas ao mesmo tempo. Pra isso existe o grid.
  • grid-template-columns = o molde das colunas. Primeiro 4 colunas de 50px: desenhei o tabuleiro.
  • Troca pra 1fr: fr = fração, uma fatia. O espaço é cortado em 4 fatias iguais, sem fazer conta.
  • span 2: “ocupe duas casas”. Reparem que os outros botões se encaixam sozinhos.
  • height: auto no alto: senão os 52px travam ele.

Erro comum

  • Colocar display: grid nos botões em vez da caixa .teclas. Igual ao flex: a regra vai no pai.

Tempo

  • 3:00 → 5:00

Com ↓ (só você)

  • Um só ↓: muda para 5 colunas, os operadores vão pra 5ª coluna (.op, .alto), e a caixa fica mais larga.
  • O HTML não muda (só as classes op que já estavam lá). A ordem dos números fica diferente, de propósito.

Falar

  • Olha o poder do grid: mudei o layout inteiro só no CSS. Na table eu teria que reescrever o HTML.
  • Cinco 1fr +grid-column: 5 manda os operadores pro lado. grid-auto-flow: dense preenche os buracos.
