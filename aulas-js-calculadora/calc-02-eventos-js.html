A ideia

O botão é a campainha. O JS atende a porta.

botao.addEventListener('click', function () {  console.log('alguém tocou!');});
quem? o botãoquando? no cliqueo que fazer?

Falar

  • Evento = algo que acontece na página: um clique, uma tecla, alguém digitando, um formulário enviado.
  • O JS fica “de ouvido” esperando. Quando a campainha toca, ele roda a função.
  • Toda vez é a mesma receita, com 3 perguntas: quem? quando? o que fazer? (apontar as cores).
  • Clicar na campainha algumas vezes: cada clique = a função roda de novo.

Falar

  • O HTML do formulário já vem pronto no zip: 2 caixas de número, a operação, o botão e o <output> onde vai o resultado.

Falar

  • document.querySelector('#calc'): “JS, vai na página e me traz o elemento com id calc”.

Com ↓ (só você)

  • Começa no código do slide anterior (clicar no = pra mostrar o pisca de novo) → ↓ event + event.preventDefault() → clicar no = (agora fica).

Falar

  • Formulário tem um costume antigo: quando é enviado, ele recarrega a página (era assim que se mandava dados pro servidor).
  • event é um “bilhete” que o navegador entrega pra função, com tudo sobre o que aconteceu.
  • preventDefault() = “não faz o que você faria normalmente”. Agora quem manda é o nosso JS.

Erro comum

  • Esquecer o preventDefault: o resultado aparece por meio segundo e some. Se a página “pisca”, é isso.

Com ↓ (só você)

  • Passos: pega n1, n2 e resultado → ↓ resultado.textContent = n1.value + n2.value → clicar no = (dá 23) → ↓ Number() → clicar no = (dá 5).
  • As caixas já vêm com 2 e 3.

Falar

  • .value = o que a pessoa digitou na caixa. .textContent = o texto que aparece dentro do elemento.
  • 2 + 3 = 23?! Deixar eles tentarem explicar antes.
  • Tudo que vem de uma caixa de texto é texto, mesmo com type="number". E texto + texto = juntar: “2” + “3” = “23”.
  • Number() transforma o texto em número de verdade.

Erro comum

  • Somar .value direto. Funciona pra -, * e / (o JS converte sozinho), só o + quebra. Por isso é traiçoeiro.

Recap

A calculadora funciona

  • addEventListener: quem? quando? o que fazer?
  • 'submit': o form foi enviado
  • event.preventDefault(): não recarrega a página
  • .value é sempre texto → Number()
  • .textContent: escreve na página
  • 'input': a cada tecla
